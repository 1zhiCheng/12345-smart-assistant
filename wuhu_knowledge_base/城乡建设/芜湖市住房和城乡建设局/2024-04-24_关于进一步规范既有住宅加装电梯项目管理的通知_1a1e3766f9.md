# 关于进一步规范既有住宅加装电梯项目管理的通知

各区人民政府 :

为进一步规范我市既有住宅加装电梯工作，保护人民群众的合法权益，现就既有住宅加装电梯项目管理通知如下。

## 一、加强前期工作

(一)报备加装意愿。 有意向申请加装电梯的业主以单元 ( 幢、栋 ) 为单位，在与加装电梯企业达成协议之前，需推选出业主代表向属地社区报备加装电梯意愿。业主代表报备后，属地社区通过召开“业主见面会”等形式，详细了解本单元业主加装意愿和意见建议，区住建部门、街道、加装电梯企业均可参加。属地社区应做好加装电梯政策法规宣传，做好风险提示 ( 比如批前付费存在风险等 ) ，并形成台账上报区住建部门。区住建部门掌握业主加装意愿后，应会同相关区直部门、属地街道、社区进行现场初勘，判断是否具备加装条件，若条件不具备，将不利条件、法规限制等事项告知申请加装业主代表。

(二)规范方案公示。 建设主体进行方案公示时应明确加装位置与周边关系、连廊设置，写明属地社区办公电话，确保在本单元口、小区公示栏、主出入口公示，同时要尽可能减少不必要的批前费用发生。属地社区要跟踪居民业主意见反馈，确保装梯相关业主知情权，如反对意见较多，及时组织召开多方协调会，并向区住建部门报送情况。

(三)细化合同条款。 区住建部门应做好申请加装业主与加装电梯企业之间合同签订的指导，合同条款中应明确电梯工程总造价、付款周期、有无预付款项 ( 预付款一般不超过总造价 10%) 及加装时限。如有预付款项，应约定解除合同的退款事项、合同纠纷的解决渠道。

(四)压实主体责任。 区住建部门、属地街道、社区应落实加装电梯业主主体责任。本幢或本单元同意并出资加装电梯的相关业主为加装电梯建设主体，建设主体对加装电梯工程全过程的安全生产负总责，必须自行聘请第三方监理单位对电梯加装全过程进行质量安全监督，不得委托加装电梯企业聘请监理单位。建设主体在委托加装电梯企业实施加装电梯项目时，应签署加装电梯全过程质量安全管理承诺书。

## 二、严格程序审查

(一)受理材料。 按照省、市既有住宅加装电梯相关文件和申报材料受理清单等要求，由区住建部门受理建设主体提交的申报材料，并逐项审查材料，针对明显存在问题的材料、缺项材料一次性告知业主代表，同时提示有可能发生的矛盾纠纷等不确定因素和各类风险。

(二)区级初审。 区住建部门应同属地社区核实居民矛盾纠纷和反对意见情况，联合区级相关部门、属地街道、社区组织现场勘察，结合前期申报材料审查情况形成初审意见，并反馈属地街道社区和申请加装业主代表。

(三)联合审查。 完成区级初审并将具备联合审查条件的单元，由区住建部门上报市既有住宅加装电梯领导小组办公室，经审阅文件资料后，市既有住宅加装电梯领导小组会同区住建部门进行现场勘察，并组织市既有住宅加装电梯领导小组成员单位召开市级联合审查会，由区住建部门汇报既有住宅加装电梯申请情况。

(四)批复申请。 根据《芜湖市人民政府办公室关于修改 < 芜湖市既有住宅增设电梯办法 ( 试行 )> 的决定》 ( 芜政办 [2022]2 号 ) 和市级联合审查会意见，市既有住宅加装电梯领导小组办公室出具联合审查意见至区住建部门，由区住建部门就加装电梯开工申请进行复函。

## 三、强化过程监管

(一)跟进施工进展。 对联合审查通过的单元，区住建部门应会同属地街道、社区跟进施工进展，督促相关责任方按照合同约定及时开工、按时完工，及时召开协调会依法化解各类矛盾，杜绝烂尾工程。

(二)严格安全检查。 区住建部门会同属地街道、社区做好安全质量检查，下达安全提示单，压实建设主体和电梯公司安全责任，发现质量安全隐患问题，及时下达整改通知书，确保施工质量安全。

## 四、抓好后续管理

(一)明确管理单位。 严格按照省住建厅《关于加强既有住宅增设电梯使用管理的通知》 ( 建房函 [2023]635 号 ) 要求，由属地社区告知业主代表，建设主体须委托物业服务企业、维护保养单位或者专业公司等市场主体管理电梯，受委托方是电梯使用管理单位。

(二)做好督促指导。 区住建部门应会同市监部门做好加装电梯管理工作的督促指导，增设电梯的单元应当确定后续运维管理方案，建设主体在委托使用单位时，约定电梯管理具体服务事项，并跟踪了解电梯交付后运行保养管理协议履行情况，是否正常履行管养义务和责任。
