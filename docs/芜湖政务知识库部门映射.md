语料只采集 `*.wuhu.gov.cn` 官方网站公开内容。优先保留条例、办法、办事指南、政策解读、常见问题、职责清单、投诉处理与维权指引，排除招聘、采购、中标和一般会议新闻。当前白名单语料共 56 篇，12 个类别每类不少于 3 篇。

`wuhu_knowledge_base/manifest.jsonl` 是机器可读清单，`source_inventory.csv` 可直接用 Excel 审核，`summary.json` 包含分类数量和短文档质检结果。

采集命令：

```powershell
$env:PYTHONPATH='backend'
.\.venv\Scripts\python.exe -m scripts.crawl_wuhu_knowledge `
  --output .\wuhu_knowledge_base `
  --curated-file .\backend\scripts\wuhu_curated_sources.json

# 白名单变更后，清理已下载文件并重建清单
$env:PYTHONPATH='backend'
.\.venv\Scripts\python.exe -m scripts.reconcile_wuhu_knowledge `
  --root .\wuhu_knowledge_base `
  --curated-file .\backend\scripts\wuhu_curated_sources.json
```

导入命令：

```powershell
$env:PYTHONPATH='backend'
.\.venv\Scripts\python.exe -m scripts.ingest_department_files `
  --base .\wuhu_knowledge_base `
  --skip-conflicts `
  --skip-metadata-llm
```

上述首次批量建库命令不会调用 LLM，适合快速建索引。后续可对审定的重点政策单独执行元数据抽取和冲突检测。
