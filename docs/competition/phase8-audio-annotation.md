# 阶段 8：录音人工标注与语义字段评测

## 验收结论

录音质量评测已从单一字符相似度扩展为可复现的标注与评测闭环。系统现在分别计算 CER、角色
序列准确率、带人工时间戳的 DER、语义字段 F1、字段支持精确率和路由指标。没有人工说话人
时间戳时，报告明确把 DER 标记为不可用，不再用“双角色检出率”替代 DER。

36 条合成双人通话开发集已完成标注格式迁移并通过本地真实 BGE 评测。18 条比赛真实录音的
私有标注模板已生成在 Git 忽略目录中。18/18 已生成 `machine_draft`，18/18 含时间片，17/18
检出接线员与群众双角色，但目前仍为 0/18 人工批准，不据此修改规则或阈值。模板已为 18 条工单
写入本地相对 `audio_ref`；工作台选择数据集录音根目录后可自动匹配并随工单切换播放。
新增本地半自动预标注：faster-whisper 生成角色化转写和时间戳，工单 Agent 生成字段与路由建议；
结果强制标为 `machine_draft`，已有比赛 Excel 标签优先保留，只有人工批准后才能进入正式评测。

## 实现

- `app/evaluation/audio_annotations.py`：标注构建与校验、CER、角色序列、帧级 DER、语义字段
  精确率/召回率/F1、公开报告隐私检查。
- `scripts/audio_annotation_dataset.py`：提供 `init-synthetic`、`init-official`、`validate`、
  `score`，并强制使用本地真实 BGE。
- `scripts/audio_annotation_workbench.html`：本地音频播放、变速播放、单时间片试听、逐字稿与时间戳
  标注、风险提示、机器建议对照、批准前硬门禁与 JSON 导出；真实冻结录音缺时间戳、含未知角色
  或缺任一通话角色时禁止批准，不向服务器上传数据。
- `evaluation/audio_annotations.synthetic.dev.json`：36 条、12 类合成开发标注。
- `local_evaluation/audio_annotations.official.private.json`：18 条真实录音私有模板；目录已被 Git 忽略。

旧字符阈值字段通过率为 38.89%，新增语义字段 F1 为 79.78%。两者评估对象不同，不能直接把
79.78%写成原指标从38.89%提升到79.78%。新结果说明字符相似度会低估语义等价改写，也显示
约20%的字段要点仍需要继续改进。

## 数据边界

- 合成集是开发集，可以用于调试，不能代表真实热线泛化效果。
- 真实比赛录音继续冻结。完成脱敏逐字稿和时间戳后只执行一次正式复评。
- 官方 Excel 是整理后的工单，不是逐字稿，不能用于计算 CER 或 DER。
- 公开报告不包含逐字稿、字段正文、音频路径和身份信息。
