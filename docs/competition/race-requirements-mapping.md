# 比赛要求与系统能力映射

依据比赛官网的赛题说明与复赛提交要求整理，核对日期为 2026-09-16。官网原文：
<https://cvmart.net/race/11419/des>。

## 必选链路

| 比赛要求 | 当前系统实现 | 演示证据 | 状态 |
| --- | --- | --- | --- |
| 录音或文本输入 | 文本录入、音频上传、本地 faster-whisper turbo 转写、音频播放与人工校对 | 营业员“诉求受理”工作台 | 已实现 |
| 要素理解与缺失提示 | 时间、地点、人物、事件、诉求等字段抽取；缺失项、多事项和歧义提示 | 工单草稿、补充追问 | 已实现 |
| 标准工单生成 | 标题、摘要、正文、关键字段、类别草稿；逐字段保留原文证据 | “分析诉求并生成工单” | 已实现 |
| 分类与承办单位推荐 | 12 类事项分类、主办部门和候选协办部门 Top-K、推荐理由、风险提示 | 部门管理员“工单处置” | 已实现 |
| 政策依据与回复辅助 | BM25 与本地 BGE 混合检索，输出官方文档引用、答复草稿、回访口径 | 政策依据和回复审核区 | 已实现 |
| 人工审核闭环 | 草稿不能自动转派或发送；营业员确认后交接，部门管理员领取、修改、提交结果 | `draft → confirmed → processing → completed` | 已实现 |
| 一条连通流程 | 统一 `StandardWorkOrder` 贯穿受理、转派、检索和回复 | 两类案例端到端演示 | 已实现 |

## 复赛提交要求

- 可运行的智能体演示，至少覆盖两种不同事项类型。
- 方案 PPT 或 PDF，包含使用说明、测试样例与结果、数据、模型和第三方工具说明。
- 3 至 5 分钟演示视频，并保证演示账号和链接在评审期间有效。
- 压缩包命名为 `赛题名称-团队名称-作品名称.zip`，团队名称在提交前填写。

## 不应在答辩中夸大的结果

- 18 条真实比赛录音全部跑通，但严格字段通过率只有 5.55%，部门 Top-1 为 33.33%。
  这组数据是未调参真实基线，说明转写噪声后的工单整理仍是首要风险。
- 冻结文档留出集语义路由 Top-1 / Top-K 为 95.83% / 95.83%，它验证的是基于官方正文的
  分类泛化，不等同于真实电话端到端准确率。
- 检索 P95 1.02ms 只代表当前单机、1,884 向量的内部检索，不包含 ASR、外部大模型网络时延，
  也不能外推成生产集群容量。
