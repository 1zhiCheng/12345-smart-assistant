# 阶段 5：政策回复合规评测与发布门禁

## 验收结论

阶段 5 已完成。政策回复现在同时经过语义校验、确定性合规门禁和人工审核；自动门禁通过
只表示草稿可提交工作人员审核，系统不存在自动发布路径。11 条官方政策问答离线全量基线
和 3 条已配置大模型代表性烟测均通过质量阈值。

## 运行时门禁

`ReplyComplianceGate` 在推荐草稿和人工修改后的最终回复两个入口执行相同检查：

- 回复正文非空；
- 引用结构完整，且引用切片必须能从后端存储重新读取；
- `[来源N]` 编号不得越界，政策性结论必须有段落级来源；
- 回复中的数字事实必须能在工单或引用原文中核对；
- 拦截保证办结、保证赔偿等越权承诺；
- 拦截完整个人手机号和身份证号；
- LLM 语义校验不得以 `passed=true` 携带真实问题绕过重写。

推荐接口返回 `release_gate`、逐项检查和草稿指纹；不通过时状态为 `blocked`。管理员回写
最终回复时会重新读取可信引用并计算门禁，不通过返回 HTTP 422。通过后仍由服务端记录
`reviewed_by`、`reviewed_at`，且 `can_auto_publish` 永远为 `false`。

管理端“工单处置”页面已展示门禁通过/拦截状态、得分和问题原因，明确提示不会自动发送。

## 生成与检索可靠性修复

- 答案模型显式关闭高强度思考，避免有限输出预算耗尽后 `content` 为空。
- 空输出立即降级为带来源编号的官方原文摘录。
- 初稿及最多两次重写均重新校验；最终重写不再漏验。
- 连续语义校验失败时改用官方原文摘录，再执行确定性门禁和人工审核。
- 统一生成器和校验器的 `[来源N]` 格式，过滤“引用一致、不构成错误”等说明性伪问题。
- 原问题、确定性政务扩展和一条模型改写并行检索；复合问句拆成子问题，每个子问题至少
  保留一条最高位有效证据，避免单一主题挤掉其他诉求。
