# 芜湖12345双人合成训练集（第一批）

- 规模：12个类别，每类3条，共36条。
- 形式：每条为5轮双角色通话，包含接线员开场、群众描述、接线员追问、群众补充、接线员复述确认。
- 声线：群众男声18条、女声18条；接线员与群众在同一通电话中使用不同性别声线。
- 文件：每条录音为16kHz单声道WAV，并提供同名UTF-8逐字稿；每类提供一份8列标准工单Excel。
- 属性：全部为虚构、脱敏、合成训练数据，不是真实12345通话，不得计入官方评测成绩。
- 口音说明：采用生活化的芜湖本地普通话表达，不冒充纯正芜湖方言。
- 已知挑战：当前ASR偶尔把“芜湖/镜湖”等本地地名识别为同音词；现有规则降级未做说话人分离，可能把接线员追问并入群众诉求。这批数据可用于后续地名热词纠错和角色分离评测。
